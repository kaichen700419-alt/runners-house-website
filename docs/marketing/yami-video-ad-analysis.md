## 4. 核心診斷:一句話

**視覺模板和品牌定位打架** —— 賣的是「乾式熟成、星空餐酒、職人」的高端定位,
用的卻是萊姆綠+卡通字體+檸檬插圖的平價快餐模板,
而且「YUMMY RESTAURANT」這個模板預設英文名的版面比「晶澤亞覓」還大。
高端餐飲的視覺語言應該是:深藍/黑底、金色或米白細明體(serif)、大量留白、慢而穩的鏡頭。

## 5. 重剪方案

### 方案 A|零拍攝,現有素材重剪(1–2 天可完成)

風格全面換掉:深藍夜色底 + 金色/米白明體字,刪除所有綠色模板元素與 YUMMY RESTAURANT。

| 時間 | 畫面 | 字卡 |
| ---- | ---- | ---- |
| 0–3s | 熟成肋眼牛排特寫照,Ken Burns 緩推 | 大字:「21 天,只為這一口。」 |
| 3–6s | 牛排/梅花豬照片 ×3 快切,卡節拍 | 「日月潭唯一|乾式熟成」 |
| 6–8.5s | 星空屋內景(避開空氣清淨機構圖裁切) | 「在星空下開動」 |
| 8.5–12s | 結尾資訊卡:Logo + 品牌名 | 「晶澤亞覓餐廳|晶澤飯店 2F」<br>「📞 049-7008188|私訊『訂位』」 |

同步輸出 9:16 版(照片上下延伸模糊底或重新構圖)與 4:5 版。

### 方案 B|加拍半天動態鏡頭(成效最大化,強烈建議)

手機 + 穩定器即可,拍 4 顆鏡頭:

1. **牛排下鍋/炙燒瞬間**(滋滋聲收音!)— 開場 0–1 秒用它,聲音鉤子 + 油煙視覺是牛排廣告 hook rate 最高的開法
2. **切開熟成牛排斷面**,粉紅斷面 + 肉汁
3. **熟成櫃開門**,吊掛肉塊 + 霧氣(「21 天」的視覺證據)
4. **星空屋內倒精釀啤酒**,氣泡 + 背景燈串散景

結構:滋滋開場(0–2s)→ 切面 + 「21 天乾式熟成」(2–5s)→ 熟成櫃 + 「日月潭唯一」(5–8s)
→ 星空屋座席氛圍(8–11s)→ 資訊卡 CTA(11–15s)。

### 兩案共同修正

- 響度統一 normalize 至 **-14 LUFS**,換用有商用授權音樂(Meta Sound Collection 選 cinematic/jazz 類)
- 「首間」vs「唯一」擇一、全素材統一,且需可佐證(廣告不實檢舉風險)
- 戶外圓頂那張過度修圖的照片換成實拍,避免到店落差
- 所有文字收進中央 80% 安全區
